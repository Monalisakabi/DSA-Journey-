## 🧠 Key Concepts

### 1. Methods
A method is a reusable block of code that performs a specific task.

### 2. Parameters and Arguments
- **Parameters:** Variables declared in a method definition.
- **Arguments:** Actual values passed when calling the method.

### 3. Return Values
A method can return a result using the `return` keyword.

### 4. Boolean Methods
Boolean methods return either `true` or `false`, useful for decision-making.

### 5. Method Overloading
Multiple methods can share the same name if their parameter lists differ.

### 6. Static Methods
Static methods belong to the class and can be called without creating an object.

### 7. Instance Methods
Instance methods belong to an object and are typically called using an object reference.

### 8. Recursion
Recursion occurs when a method calls itself to solve a problem.

- **Base Case:** Stops recursive calls.
- **Recursive Case:** Calls the method again with a smaller or simpler input.
