## 🧠 Important Concepts Learned

- Variables are used to store data.
- Java provides different data types such as `int`, `double`, `char`, and `boolean`.
- Scanner is used to accept user input.
- System.out.println() displays output.
- Arithmetic operators perform mathematical calculations.
- Relational operators compare two values.
- Logical operators combine multiple conditions.
- Type casting converts one data type into another.
- Basic Java programs follow a class and main method structure.
