## 🧠 Important Concepts Learned

- Conditional statements control program execution based on conditions.
- If-else statements help make decisions.
- Else-if ladders handle multiple conditions.
- Switch statements provide multiple execution choices.
- For loops are useful when the number of iterations is known.
- While loops execute as long as a condition remains true.
- Do-while loops execute at least once.
- Break terminates a loop.
- Continue skips the current iteration.
- Nested loops allow repeated operations inside another loop.

## 🔍 Logic Examples

### 1. Even or Odd
- Use the modulus operator `%`.
- If the remainder after division by 2 is zero, the number is even.
- Otherwise, it is odd.

### 2. Largest of Three Numbers
- Compare three numbers using conditional statements.
- Identify the number greater than or equal to the others.

### 3. Factorial
- Initialize the factorial variable with 1.
- Multiply it by every integer from 1 to N.

### 4. Reverse a Number
- Extract the last digit using `% 10`.
- Add the digit to the reversed number.
- Remove the last digit using `/ 10`.

### 5. Prime Number
- Check divisibility starting from 2.
- If any number divides it completely, it is not prime.
- Otherwise, it is prime (for numbers greater than 1).
