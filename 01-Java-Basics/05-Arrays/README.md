## 🧠 Key Concepts

### 1. Arrays
An array is a data structure that stores multiple elements of the same data type under a single variable name.

### 2. Array Declaration
Arrays can be declared using the following syntax:

```java
int[] numbers;
```

### 3. Array Initialization
An array can be initialized with values:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

### 4. Array Indexing
Array indexing starts from `0`. Each element can be accessed using its index.

### 5. Array Traversal
Traversal means visiting each element of an array using loops.

### 6. Array Length
The `length` property returns the total number of elements in an array.

### 7. Enhanced For Loop
The enhanced `for` loop is used to access array elements without manually managing indexes.

### 8. Sum and Average
The sum is calculated by adding all array elements. The average is calculated by dividing the sum by the total number of elements.

### 9. Maximum and Minimum
Maximum and minimum elements can be found by comparing each element with the current maximum and minimum values.

### 10. Two-Pointer Technique
The two-pointer technique uses two indexes, usually starting from opposite ends of an array, to perform operations such as reversal.

### 11. Swapping
Swapping exchanges the values of two array positions using a temporary variable.

### 12. Linear Search
Linear search checks each element sequentially until the target element is found or the array ends.
