## 🧠 Important Concepts Learned

- Outer loops control the number of rows.
- Inner loops control the number of columns.
- Spaces help align pyramid and diamond patterns.
- Nested loops are useful for creating complex patterns.
- Conditional statements help create hollow and binary patterns.
- Loop variables control the number of stars and numbers printed.
- Multiple loops can be combined to create symmetrical patterns.

## 🔍 Pattern Logic Examples

### 1. Square Pattern
- Rows: Fixed
- Columns: Fixed
- Every row contains the same number of stars.

### 2. Right Triangle
- Outer loop controls rows.
- Inner loop runs from 1 to the current row number.
- Number of stars increases with each row.

### 3. Pyramid Pattern
- First loop prints spaces.
- Second loop prints stars.
- Spaces decrease while stars increase.

### 4. Hollow Square
- Stars are printed on the boundary.
- Spaces are printed inside the square.
- Uses conditional statements inside nested loops.
