# 📚 Array Basics – DSA Journey

This folder contains fundamental array-based problem-solving exercises implemented in Java as part of my DSA learning journey.

## 🎯 Topics Covered

- Finding the largest element in an array
- Finding the smallest element in an array
- Finding the second-largest distinct element
- Checking whether an array is sorted
- Reversing an array using the two-pointer technique
